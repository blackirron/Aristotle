# Aristotle

Your digital AI teacher — pick a topic, and get taught it properly, not just handed a summary.

🔗 **Live demo:** https://aristotle.bolt.host

## What it does

Aristotle acts as a patient, structured tutor: give it a subject or concept and it breaks the teaching down step by step, the way a good human teacher would — building from fundamentals, checking understanding, and adapting explanations rather than dumping a wall of text.

## Status

Built and deployed as a Bolt project; the live app is the source of truth. This repository tracks the project on GitHub as a reference point — see the demo link above for the actual product.
